# 🌸 모란 한 조각

모란역 골목(도담길)에 숨은 가게를 GPS로 찾아 카드로 모으는 골목 탐험 웹 게임입니다.
설치 없이 휴대폰 브라우저에서 실행됩니다. (빌드 과정 없음 — 정적 파일만으로 동작)

## 실행

```bash
python3 -m http.server 8123
```

브라우저에서 `http://localhost:8123` 접속. 휴대폰에서 GPS를 쓰려면 **HTTPS 주소**에 올려야 합니다
(GitHub Pages, Netlify, Vercel 등에 이 폴더를 그대로 올리면 됩니다).

## 기능

| 기능 | 설명 |
|---|---|
| 3D 골목 지도 | madekey.kr 과 같은 실제 도로 좌표로 만든 아기자기한 3D 맵 (건물은 장식) |
| GPS 탐험 | 실제 위치를 따라 캐릭터 "모랑"이 움직임. 모란 밖에서는 둘러보기 모드(화면을 끌어 이동) |
| 숨은 가게 알람 | 55m 안에 들어오면 소리·진동·알림, 20m 안에서 "발견하기" |
| 가게 페이지 | 메뉴판, 진행 중 이벤트, 담벼락(사진 피드), 방명록, SNS 공유 |
| 카드 수집 | 발견하면 카드 획득. 방문 3회 = 단골, 7회 = 찐단골 등급 |
| 가게 카드 이미지 | `js/shops.js`의 `image` 또는 설정 → 사장님 모드에서 등록 |
| 메이드키 조각 카드 | 메이드키 방문 시 원하는 사진을 정사각형으로 잘라 나만의 카드로 수집 |
| 코스 공유 | 다녀온 가게를 순서대로 골라 지도+목록 이미지로 만들어 SNS 공유 |

## 지도와 가게 데이터 (madekey.kr 기준)

- **골목 지도**: `data/roads.json` — madekey.kr 과 같은 실제 도로 좌표(OpenStreetMap, ODbL).
  `node tools/build-map.mjs` 로 `data/map.json`(게임용, 메이드키 중심 반경 600m)을 다시 만듭니다.
  건물 외곽선 데이터는 없어서 골목 옆 건물은 **장식용**으로 자동 배치됩니다.
- **지도 기준점**: `js/geo.js`의 `CENTER` = 메이드키 좌표.
- **가게**: `js/shops.js` 에는 메이드키만 들어 있습니다. 나머지는 고객이 골목을 걸으며
  지도 화면의 **📍 가게 등록** 버튼으로 지금 서 있는 자리에 직접 등록합니다(이름·카테고리·한 줄 소개, 카드 사진).
- **지도 보기 전환**: 지도 화면의 **🎮 게임 지도 / 🗺️ 구글 지도** 탭. `js/config.js`의 `GOOGLE_MAPS_KEY`가 비어 있으면
  현재 위치만 찍힌 간단한 구글 지도가 열리고, 키를 넣으면 내 위치와 발견한 가게 마커가 구글 지도 위에 표시됩니다.

## 서버 연결 (madekey.kr)

`js/api.js` 가 madekey.kr 의 기존 서버(`/api/game`, `/api/places`, `/api/upload`, `/api/photo`)를 사용합니다.

- 연결되면: 가게 등록·방문 기록·담벼락 사진·방명록이 서버에 저장되어 **모든 고객과 공유**됩니다.
  다른 고객이 등록한 가게는 내 지도에 "숨은 가게"로 나타납니다(1분마다 새로 받아옴).
- **게임을 madekey.kr 과 같은 주소에 올려야 연결됩니다.** 서버가 다른 주소의 요청(CORS)을 허용하지 않기 때문입니다.
  다른 주소(예: localhost)에서는 자동으로 "이 기기에만 저장" 방식으로 동작합니다. (`js/config.js`의 `API_BASE`)
- 나의 조각 카드, 카드 등급, 가게 카드 사진은 서버에 해당 기능이 없어 기기에만 저장됩니다.

## 지금 버전의 한계

- 서버에 연결되지 않은 주소에서는 등록한 가게·방명록·사진이 **각자의 기기에만** 저장됩니다.
- 알람은 앱 화면이 켜져 있을 때만 울립니다(웹 브라우저의 제약). 화면이 꺼진 상태의 알림은 네이티브 앱이 필요합니다.
